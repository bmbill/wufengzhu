# 無風燭・奢摩他練習

廣論奢摩他章的個人練習網站（手機用）。

- **今日**：上座（語音引導）、本週聽講（真如老師《廣論止觀初探》，在網頁裡直接聽）、呼吸警報、睡前反省；燭燭和小安以貼圖出現在卡片邊角提醒你
- **進度**：153 盞燈（聽完的講次）、燈油與主題收藏、上座紀錄、沉掉統計、九個階梯
- **檢核**：六個檢核點，沒過會告訴你怎麼補
- **調整**：聽講速度、座時、所緣、請假、回溫、備份、第二章開關
- **第二章・毗缽舍那**：止觀初探・毗缽舍那聽講（老師還在講，每週自動更新）、每天選做的「觀察修 5 分鐘」與觀察筆記

「由止力故如無風燭，諸分別風不能動心。」——《修次中篇》，廣論奢摩他章引

## 放到手機上

1. 用手機打開網址（GitHub Pages）。
2. iPhone：Safari →「分享」→「加入主畫面」。Android：Chrome 選單 →「加到主畫面」。
3. 進度只存在這支手機的瀏覽器裡。請偶爾到「調整 → 下載備份檔」，換手機時用「從備份檔還原」。

## 角色圖與主題（燈油獎勵）

完成任務會累積「燈油」：上座一座 +2（每天最多兩座）、聽完一講 +3、保底一分鐘 +1、呼吸警報 +1、睡前反省 +1、通過檢核 +5。
累積到 15／40／80／130／200 滴，依序解鎖「蓮池、調象、月夜、山林、海洋」主題，每個主題是一對新的角色（引導者＋學員），在「進度」頁切換。

角色圖用 ChatGPT 一次產生 4×4＝16 張（引導者 8 種＋學員 8 種表情），提示詞在 **`角色提示詞.md`**。
產生後執行 `python tools/slice_sheet.py 圖檔.png 主題代號`，會自動切成 16 張、去背、放進 `chars/<主題>/`，並更新 `chars/files.js`。
還沒有圖的主題，網站會用內建的簡單角色。

## 聽講

`lectures.js` 是 153 講的音檔清單（取自大慈恩譯經基金會的 Podcast RSS），網頁底部的播放列直接播放，會記住聽到哪裡、可調倍速、手機鎖屏也能控制。全文仍連到大慈恩網站。

## 研討式聽講（參考真如老師《如何研討廣論》）

每一講建議聽三遍（每週 1 講，三遍都在同一週）：

1. **分段聽清楚**：每 5 分鐘自動暫停，用一句話寫下這段在講什麼，聽不清楚可以重聽這段；聽完回答「這講要成立什麼、用什麼證明」「我心裡有沒有不承許的想法」「哪一句最打動我」。
2. **聽出新的**：整講再聽，寫下這一遍多聽到什麼。
3. **體會心意**：再聽一次，寫下老師想教我什麼，最後才想用在生活的哪件事。

每一遍前有語音帶「聽前發心」。每講標出它在次第中的位置（念珠）。聽完後第 1、3、7 天，今日頁會出現「回想一下」：先在心裡回想，再翻開自己的筆記對照。第 2、3 遍各 +1 燈油。

## 第二章・毗缽舍那

在「調整」頁開啟（奢摩他入門線聽完時也會提醒）。開啟後今日頁多一張毗缽舍那聽講卡，和選做的「觀察修 5 分鐘」：皈依發心 → 調身調息 → 語音念出觀察題 → 安靜思惟 → 寫一句觀察筆記 → 迴向。

觀察題跟著聽講進度換：為何要觀 → 我執是苦根（聽完第 28、32 講）→ 認識所破（聽完第 47～49 講）。題目是學習用草稿，請以帶修法師的指導為準。

`lectures_vip.js` 由 `tools/update_vip.py` 從大慈恩 Podcast RSS（B000211）產生；`.github/workflows/update-vip.yml` 每週日自動更新並提交。

## 語音

引導語音是預先用 Azure「曉曉・溫柔語氣」錄好的 mp3（`voice/`），破音字用拼音指定讀音（例如 數[shu3]呼吸、調[tiao2]身、重[chong2]來、為[wei4]利有情）。破音字表沿用備覽小教室的 `READ`，再加上本網站的詞（`tools/make_voice.py` 的 `APP_READ`）。

改了引導詞以後重新錄音：

1. 用電腦開網站，在瀏覽器主控台執行 `copy(JSON.stringify(allVoiceLines()))`，貼到 `tools/lines.json`。
2. `python tools/make_voice.py tools/lines.json`（金鑰讀 `%USERPROFILE%\.beilan-azure\speech.json`，不會進 repo）。

沒有錄音的句子，會改用手機內建的中文語音。
