# 燈燈相續・廣論聽聞與實修

菩提道次第廣論的個人學習網站（手機用），照戒、定、慧次第：

- **戒**：每天一段師父南普陀廣論（大慈恩 B000027 第 1～284 卷，道前基礎到四攝，32 個法類、約 2300 段，每段 3～5 分鐘）。可選「法類順序（選一個法類照順序聽）／自選／隨機」。每次先聽約 2 分鐘的聞法勝利（不能跳過），停 10 秒思惟，再接正式段落；每段都有主題與目標（AI 讀過師父完整講解後寫初稿，再讀完整講解打磨一輪，打磨準則在本機的 tools/out/polish/BRIEF.md，不在 repo 裡，`tools/lr_topics.json`；`tools/merge_topics.py` 合併），聽完對照目標打勾、用一句話寫這段在講什麼。聽完一個法類蓋一個印章。
- **定**：奢摩他上座實修（語音引導、九階）、真如老師《止觀初探・奢摩他》：基本是完整聽一次、心裡做結論；進階是研討式聽三遍。
- **慧**：《止觀初探・毗缽舍那》與觀察修（第二章）。

「譬如一燈燃百千燈，冥者皆明，明終不盡。」——《維摩詰所說經・菩薩品》

- **今日**：上座（語音引導）、本週聽講（真如老師《廣論止觀初探》，在網頁裡直接聽）、呼吸警報、睡前反省；燭燭和小安以貼圖出現在卡片邊角提醒你
- **進度**：153 盞燈（聽完的講次）、燈油與主題收藏、上座紀錄、沉掉統計、九個階梯

- **第二章・毗缽舍那**：止觀初探・毗缽舍那聽講（老師還在講，每週自動更新）、每天選做的「觀察修 5 分鐘」與觀察筆記


## 放到手機上

1. 用手機打開網址（GitHub Pages）。
2. iPhone：Safari →「分享」→「加入主畫面」。Android：Chrome 選單 →「加到主畫面」。
3. 進度只存在這支手機的瀏覽器裡。請偶爾到「調整 → 下載備份檔」，換手機時用「從備份檔還原」。

## 角色圖與主題（燈油獎勵）

完成任務會累積「燈油」：上座一座 +2（每天最多兩座）、聽完一講 +3、保底一分鐘 +1、呼吸警報 +1、睡前反省 +1、通過檢核 +5。
累積到 15／40／80／130／200 滴，依序解鎖「蓮池、調象、月夜、山林、海洋」主題，每個主題是一對新的角色（引導者＋學員），在「進度」頁切換。

角色圖用 ChatGPT 一次產生 4×4＝16 張（引導者 8 種＋學員 8 種表情），提示詞在 **`角色提示詞.md`**。
產生後執行 `python tools/slice_sheet.py 圖檔.png 主題代號`，會自動切成 16 張、去背、放進 `chars/<主題>/`，並更新 `chars/files.js`。
還沒有圖的主題，網站會用內建的簡單角色。

## 戒・每日聽聞（師父南普陀廣論）

`lamrim.js` 由 `tools/build_lamrim.py` 產生：讀大慈恩《菩提道次第廣論手抄稿（南普陀版）》第 1～284 卷，照逐字稿裡的廣論原文段（scripture-kai）與講解段落的時間標記（data-time）切成一段段（約 3～5 分鐘），短的科判句併到下一段，太長的照講解段落再切；卷首接續上一卷的講解自成「續」段。法類的起點照廣論科判校正過，寫在 `tools/cat_bounds.json`（法類→起始段落識別碼）。每段的主題由原文自動摘出（科判句優先），目標用通用句式加上 `index.html` 裡 `LR_GOAL` 的法類目標。改了切法之後跑 `tools/lr_migrate.py`，把舊段落對照到新小段，讓已聽的進度不會掉。師父的講解逐字稿與音檔在播放時才向大慈恩讀取，不存在本網站；廣論原文照存，讓卡片離線也看得到。

`hearing.js` 是聞法勝利前行：師父講「聽聞勝利」的部分（卷 17 後段～卷 19 前段），由 `tools/build_hearing.py` 照講解段落切成 16 小段（約 2～3 分鐘），主題與目標寫在 `tools/hearing_meta.json`（`python tools/build_hearing.py` 產生切段，`python tools/build_hearing.py js` 合成）。進度以「卷.段落位置」記錄，重新產生資料也不會跑掉。

## 分段點的聲音對位

逐字稿時間和字數推算都不準，改用 faster-whisper 辨識分段點附近的聲音，拼音比對上一段最後幾個字／這一段開頭幾個字來定位：
- 戒：`tools/calib_starts.py` → `tools/start_fix.json`（build_lamrim.py 套用）
- 止觀初探、毗缽舍那：`tools/calib_segments.py` → `tools/segments_align.json`（build_segments.py 套用）
- 聞法勝利：`tools/calib_hearing.py` → `tools/hearing_fix.json`（build_hearing.py js 套用）
- 毗缽舍那新講次：這台電腦的工作排程「DengDeng-SegmentCalib」每週日 20:00 跑 `tools/local_weekly.py` 補校。

## 免手持（在路上聽）

聽完一段或一講時，先在心裡做結論，再說「繼續／完成」或「重聽」（瀏覽器的語音辨識，zh-TW；第一次會問麥克風權限）。耳機的「下一首」＝繼續、「上一首」＝重聽，螢幕鎖住時也能用。筆記欄旁有「🎙 用說的」可以語音輸入。調整頁可以關掉語音指令。

## 研討式聽講（進階，參考真如老師《如何研討廣論》）

每一講建議聽三遍（每週 1 講，三遍都在同一週）：

1. **分段聽清楚**：照內容分段，聽完一段自動暫停，用一句話寫下這段在講什麼，聽不清楚可以重聽這段；聽完回答「這講要成立什麼、用什麼證明」「我心裡有沒有不承許的想法」「哪一句最打動我」。
2. **聽出新的**：整講再聽，寫下這一遍多聽到什麼。
3. **體會心意**：再聽一次，寫下老師想教我什麼，最後才想用在生活的哪件事。

分段由 `tools/build_segments.py` 產生（`segments.js`）：有段落標題【……】的講次照標題切，其他講次照老師念的每段廣論原文切，複習或故事課照自然段落切；再依字數比例推算時間，對齊到講話的停頓上。新的毗缽舍那講次由每週的自動更新一起分段。

每一遍前有語音帶「聽前發心」。每講標出它在次第中的位置（念珠）。聽完後第 1、3、7 天，今日頁會出現「回想一下」：先在心裡回想，再翻開自己的筆記對照。第 2、3 遍各 +1 燈油。

## 第二章・毗缽舍那

在「調整」頁開啟（奢摩他入門線聽完時也會提醒）。開啟後今日頁多一張毗缽舍那聽講卡，和選做的「觀察修 5 分鐘」：皈依發心 → 調身調息 → 語音念出觀察題 → 安靜思惟 → 寫一句觀察筆記 → 迴向。

觀察題跟著聽講進度換：為何要觀 → 我執是苦根（聽完第 28、32 講）→ 認識所破（聽完第 47～49 講）。題目是學習用草稿，請以帶修法師的指導為準。

`lectures_vip.js` 由 `tools/update_vip.py` 從大慈恩 Podcast RSS（B000211）產生；`.github/workflows/update-vip.yml` 每週日自動更新並提交。

## 語音

引導語音是預先用 Azure「曉曉・溫柔語氣」錄好的 mp3（`voice/`），破音字用拼音指定讀音（例如 數[shu3]呼吸、調[tiao2]身、重[chong2]來、為[wei4]利有情）。破音字表沿用備覽小教室的 `READ`，再加上本網站的詞（`tools/make_voice.py` 的 `APP_READ`）。

改了引導詞以後重新錄音：

1. 用電腦開網站，在瀏覽器主控台執行 `copy(JSON.stringify(allVoiceLines()))`，貼到 `tools/lines.json`。
2. `python tools/make_voice.py tools/lines.json`（金鑰讀 `%USERPROFILE%\.beilan-azure\speech.json`，不會進 repo）。

沒有錄音的句子，會改用手機內建的中文語音。
