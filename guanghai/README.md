# 廣海明月學習單（網頁／PWA）

網址（發布後）：https://bmbill.github.io/wufengzhu/guanghai/
本機預覽：`__AI\.claude\launch.json` 的 `wfz`，開 http://localhost:8779/guanghai/

每一講一份學習單，照六步走：聽前準備 → 先聽師父 → 再聽老師 → 共學 → 一週練習 → 四層核對。
網頁上六步分成三段，一次只看一段：**聽聞前行**（第一步）、**正聽**（第二、三步）、**聽之後**（第四到六步）。
每完成一步，月亮亮一分；六步做完就是月圓。寫的內容只存在使用者自己的裝置（localStorage `gh-v1`），可以匯出、匯入備份，也可以印出來寫。

## 新增一講

1. 照 572 講的範本寫學習單 md，放在 `__AI\廣海明月學習單\第NNN講_學習單.md`。
   - 開頭的表格要有：廣論段落（偈頌用「」括起來）、科判位置、所屬單元、原音與逐字稿（網址）、共學場次。
   - 再加一行「師父原音」：`| 師父原音 | 00:00–01:16 https://cdn.amec.amrtf.org/volumeMedia/… |`，第二步就會出現只播這一段的播放器。
     音檔網址：在大慈恩那一講的頁面按 F12，於 Console 輸入 `document.querySelector('audio').currentSrc`；起訖時間看逐字稿段落尾的時間（師父段落結束、老師開口的那個時間）。
   - 六節標題用「## 一、…」到「## 六、…」；第二、三步的參考答案寫在「## 附錄」，用「**二、…**」「**三、…**」分段。
   - **題目不要多，盡量不要每題都寫字**：每一步只留一題核心題要寫（題目開頭加 ★），其他能點選的改點選，剩下沒標 ★ 的寫字題網頁會收進「選做」。
     - 點選題：題目下一行寫 `選項：A｜B｜C｜D`；可複選寫 `選項（可複選）：A｜B｜C`。
     - 點選題的老師答案寫在附錄同號那一條，開頭用 `答：B。` 接著寫說明（可複選用 `答：A｜C。`）；沒有標準答案的（例如「哪一句讓我最卡」）就只寫說明。網頁上選完就會顯示。
     - 第三步寫成老師的步驟清單：`1. **步驟名**（[01:16–02:11]）：說明`。括號寫這一步在整講音檔裡的**起訖**（逐字稿每段尾的時間是那段的結束時間，所以起點是上一段尾的時間），網頁上每條會有「聽這一段」的播放鈕，並可打勾「我也有做到」；最後一句 `★ 聽完寫一句：**…**＿＿＿`。
     - 第六步「★ 最後，**留一個問題去請益**」也加 ★。
   - 第四節（共學）預設使用者**沒聽過**，只寫讀的版本：一張表 `| 場次 | 從這一講的哪裡切入 | 切入點 | 怎麼帶 | 這場特別講到 |`。
     「從這一講的哪裡切入」寫法：`師父的廚房例子（[00:00–00:49]）：說明`，網頁上會顯示在最前面並可播放那一段，下面接「帶出的主題」＝切入點；怎麼帶、這場特別講到收在「看法師怎麼帶」裡。這兩欄要寫成完整的句子（法師問了什麼、大家怎麼答、法師點出什麼），讓沒參加共學的人也看得懂；不要只用箭頭串關鍵詞。
     表格後面寫「四場合起來」「共同點」等段落（網頁收在「四場合起來看」），最後一行 `★ 讀完寫一句：**…**＿＿＿`。
   - 開頭表格可加「共學錄影」一行（福智線上課程網址），第四步會附上補聽連結。
   - 第五節要有「**觸發點**：①…②…③…」、「**遇到時做四步**」（1.～4. 每條以 **粗體標籤**： 開頭）、「**提醒**：…」。
2. 在 `無風燭` 資料夾執行：`python tools/build_guanghai.py`
   → 產生 `guanghai/lessons/NNNN.json`，並更新 `guanghai/lessons/index.json`（目錄依「所屬單元」分組）。
3. 把 `guanghai/sw.js` 的 `CACHE` 版本號加一（例如 gh-v2 → gh-v3），手機上的離線快取才會更新。
4. commit、push 後，GitHub Pages 就會更新。

## 檔案

- `index.html`、`style.css`、`app.js`：網頁本體（不需要建置）。
- `sw.js`、`manifest.webmanifest`、`icon-*.png`：PWA，離線可用，可安裝到手機主畫面。
- `lessons/`：每講的資料（由 md 轉出，不要手改）。
